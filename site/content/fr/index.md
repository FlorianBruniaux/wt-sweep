Repérez les worktrees, mesurez leur taille et lisez les preuves derrière chaque verdict. La CLI macOS actuelle reste en lecture seule. Une revue ne demande ni modèle, ni service permanent, ni compte de forge.

## Premier essai

1. [Compiler les sources](/fr/docs/installation/).
2. [Essayer une démo Git jetable](/fr/docs/demo/).
3. [Lire le rapport HTML hors ligne](/fr/docs/report/).
4. [Choisir racines et cibles d’intégration](/fr/docs/targets/) pour votre propre revue.

## Lire un résultat

- **keep** : un travail observé ou un motif de conservation prime.
- **verify** : une preuve nécessaire à la décision manque.
- **cleanup_candidate** : les conditions C1–C5 actuelles sont établies. L’usage reste à vérifier.

Aucun verdict n’autorise un retrait. `apply`, sauvegarde et restauration restent indisponibles. Un commit identique ne préserve pas les notes non suivies.

Les [mesures disque](/fr/docs/disk/) gardent leur périmètre et leur couverture partielle. Les [limites des preuves](/fr/docs/evidence/) expliquent pourquoi une commande réussie peut encore contenir des inconnues.

[Claude Code et Codex](/fr/docs/assistant/) peuvent lire les mêmes preuves CLI par petits groupes.
