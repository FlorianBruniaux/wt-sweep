## [0.1.0-alpha.3] - 2026-10-17

Third read-only Apple Silicon alpha. Adds optional local-content comparison and
a copyable assistant prompt; existing cleanup verdicts are unchanged.

### Fixed

- Local-comparison reports keep their interactive controls: sidebar links without
  a tooltip no longer interrupt filters, theme switching or the Claude prompt.
  A browser regression test now opens a report generated by the CLI on a
  disposable Git repository.

### Added

- Reproducible optional-extension evaluations for #20 and #27–30, with bounded
  synthetic fixtures and explicit adoption/stop decisions.
- Worktrunk v0.80.0 compatibility tests for existing `wt sweep` dispatch:
  arguments, streams, status, precedence and real Sweep scan/review results.
- Experimental card/index provenance reader with source/date/freshness output,
  invalid-input refusals and a real recreated-path identity counterexample.
- Writer-exclusion witnesses for mappings, new opens, aliases and guard loss.
  E1 remains unproven; `apply` remains unavailable.
- APFS clone/copy creation recipe and existing-tool comparisons, preserving
  tested index/filter/ignored-file behavior on owned fixtures. No creation
  command or reclaimable-space claim is added.
- Native disk decoder and complete experimental walks with an independent
  oracle, scalar product comparison, conservation and refusal tests. The
  corrected native experiment is faster on all three fixed corpora, with fewer
  scalar metadata calls. Retain the scalar product collector until its residency,
  cancellation and system-boundary integration is qualified. Reject the earlier
  all-fallback timing campaign; no shipped product speedup is claimed.

### Changed

- Add optional local-content comparison to `review` and `plan`: explicit Git
  targets and a same-family reference checkout, separate index/disk observations,
  ignored files, conflict stages and source-linked coverage. Publish a verified
  `local-comparison.json` before its receipt, with bounded HTML/text details and
  fresh source/reference checks. Comparison does not change triage or authorize
  removal.
  Refuse physical self-reference, including path aliases; revalidate checkout
  Git administration and refuse nested bare boundaries. Persist disk absence
  witnesses. Record the approved design, revised plan, independent review and
  local acceptance evidence.

- Prepare a copyable French prompt for Claude from saved HTML entries, including
  exact path bytes, recorded verdicts, missing checks and measured sizes.
  Offer the full saved list or rows matching current filters, with a manual
  clipboard fallback. Preparation never sends data or authorizes cleanup.

- Record extension decisions and reopening conditions in both READMEs, roadmap
  and documentation index. Earlier alpha archives remain unchanged.
- Run the HTML assistant-prompt browser checks in CI, including filtered rows,
  clipboard refusal and preservation of source evidence.
- Add native correctness/sanitizer, provenance and APFS fixture checks to CI;
  keep performance campaigns separate from CI timing.

## [0.1.0-alpha.2] - 2026-10-11

Second read-only Apple Silicon alpha. The CLI verdicts and FSL-1.1-ALv2 license
are unchanged. Download a new archive; alpha.1 remains available unchanged.

[Installation and verification](docs/release.md).

### Added

- Visible recommended next checks in inventory and review reports, derived from
  captured coverage and selected verdicts. No model decision or removal authority.
- Quick status filters, largest-size shortcut and reset. Search includes the
  recorded repository path; Escape closes command search and restores focus.
- Browser regression coverage for 16 report layouts, including keyboard access,
  JavaScript-disabled reading, filters and unchanged captured evidence.

- Navigate the report workflow diagram through seven internal links, with
  keyboard access and visible hover/focus outlines. Inventory review blocks
  explain the missing review; reviewed reports link to worktree evidence.
  Enlarge transparent hit areas to keep 44px targets at a 390px viewport.
  CI exercises both report types, themes and widths, with and without JavaScript.

  allocation gauges. Capture volume statistics from verified directory descriptors
  with `--disk-usage`; preserve inode deduplication and source totals after filtering.
  Old inventories retain their sizes with an explicit missing-capacity message.
  Allocation is not an estimate of reclaimable space.

  report sections and recorded worktrees, with keyboard focus restoration.
- Browser checks in CI for dashboard gauges, command search, sections, themes,
  mobile layout, JavaScript-disabled reading and unchanged source counts,

  sections in both report types. Show readable statuses and the primary reason;
  retain raw verdicts, complete object IDs and all evidence in expandable details.

  Distinguish bare repositories, absent paths and unverified entries; filter by

  result does not rule out squash or rebase integration.

- Keep report section titles on the disclosure line and space the command-search
  shortcut without exposing its button when JavaScript is disabled.

### Read and preservation boundaries

- Git runs with controlled arguments and environment, I/O limits and timeouts.
  The CLI neutralizes executable configuration and denies implicit object downloads.
- Object reads check commit, tree and blob bytes against SHA-1 or SHA-256 OIDs,
  with SHA-1 collision detection. Missing or corrupt objects remain unknown.
- Outputs require new files outside inspected boundaries and descriptor identity
  checks. Three private unsafe boundaries are documented and reviewed: native
  mounts, materialization policy and descriptor-selected Git cwd.
- `apply` remains unavailable. E1 writer exclusion is not demonstrated; durable
  backup, independent restore and removal are blocked. The
  [finishing ledger](docs/finish-ledger.md) records local checks and remaining limits.
