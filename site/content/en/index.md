Find worktrees, measure their footprint and read the evidence behind each verdict. The current macOS CLI stays read-only. It needs no model, daemon or forge account to run a review.

## Your first run

1. [Install the alpha or build from source](/docs/installation/).
2. [Try a disposable Git demo](/docs/demo/).
3. [Read the offline HTML report](/docs/report/).
4. [Choose roots and integration targets](/docs/targets/) for your own review.

## Read a result

- **keep**: observed work or another retention reason takes priority.
- **verify**: evidence for a decision condition is missing.
- **cleanup_candidate**: current C1–C5 conditions are established. Usage still needs checking.

No verdict authorizes removal. `apply`, backup and restore remain unavailable. A matching commit does not preserve untracked notes.

[Disk measurements](/docs/disk/) retain their scope and partial coverage. [Evidence limits](/docs/evidence/) explain why a successful command may still contain unknowns.

Prefer assistance? [Claude Code and Codex](/docs/assistant/) can read the same CLI evidence in batches.
